# Kids Fun World

A colorful, responsive kids' learning and mini-games website built with plain HTML, CSS and JavaScript.

## Included
- Responsive homepage for mobile and desktop
- Shape Match, Number Fun, Letter Pop and Color Studio mini-games
- Star reward counter saved in the browser using localStorage
- Parent information dialog
- No backend, API key, build command or paid service required

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub and Vercel

### 1. GitHub
1. Sign in at https://github.com
2. Create a new repository, for example `kids-fun-world`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Commit the files.

### 2. Vercel
1. Sign in at https://vercel.com using your GitHub account.
2. Choose **Add New → Project**.
3. Import the `kids-fun-world` repository.
4. For a plain HTML site, choose **Other** as the framework preset if asked.
5. Leave Build Command and Output Directory empty (or use `.` if Vercel requires an output directory).
6. Click **Deploy**.

Vercel will provide a public website URL. When you update files in GitHub, Vercel can automatically redeploy.

## Important notes
- This is a static starter version. Stars are saved only in the same browser/device.
- There is no Firebase database, user login, cloud leaderboard or admin dashboard in this ZIP.
- Google Fonts are loaded from Google Fonts; the site still works with fallback fonts if unavailable.
